# 余下

一个个人使用的静态 PWA。按自然月管理五个预算池，每笔消费从所属预算池扣减；首页只列出当前月份及用户已新增的月份。

## 主要功能

- 五个预算池：日常生活、状态投资、成长投入、社交关系、自由消费。初始月度额度分别为 ¥2,000、¥1,200、¥1,500、¥1,000、¥2,000，可在设置里调整。调整从当月起生效，过去月份的预算保持不变。
- 每个新自然月会自动出现在首页；其他过去月份由用户点“新增月份”加入。月度详情用“202609 预算池”这样的紧凑标题，默认以五行显示各池名称、使用进度和百分比；点三角按钮可展开完整预算卡片。
- 快速记账：金额、名称、预算池是主要字段，日期默认当天。可选多个 Tag；默认提供 #可避免。支持编辑、删除、预算池筛选、日期与金额排序。
- 常用消费名称与关键词可自动选择预算池，也可手动修改。
- 固定消费每月自动计入；修改或停用从当月起生效，过去月份保留原规则。
- 分摊消费保存实际支付金额、支付日期和分摊月数，按月扣减预算。金额按分分配，所有月份计入金额之和等于实际支付金额。
- 过去月份自动显示月度复盘：总支出、总预算、结余或超支、#可避免金额，以及全部明细。
- JSON 备份导出与导入。导入会覆盖现有月度数据。

数据只存于当前浏览器的 `localStorage`，键为 `yuxia-monthly-v1`。旧旅行项目的 `yuxia-ledger-v1` 数据不会被修改或自动导入；两种数据结构用途不同。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 `http://localhost:4173`。部署到 HTTPS 后，可通过 iPhone Safari 的“添加到主屏幕”安装。更换设备或清理网站数据前，请在设置中导出备份。
